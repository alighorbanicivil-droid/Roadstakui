# RoadStake UI

برنامه‌ی وب فارسی (RTL) برای **پیاده‌سازی راه، نیوو (تراز) و برداشت** — تک‌فایل، بدون سرور، قابل نصب به‌صورت PWA و کار بدون اینترنت.

نسخه: `UI-3.9.1` (بر پایه‌ی RoadStake 1.22.1)

## امکانات

- محور و لبه‌ها، چند خیابان مستقل، کیلومتراژ به‌صورت `1+250`
- شیب عرضی و طولی، مقطع‌ها، لایه‌ها
- نیوو: HI، قرائت شاخص، ساخت بنچ‌مارک
- **کنترل بنچ‌مارک کارفرما:** ثبت X/Y/Z اندازه‌گیری‌شده، اختلاف‌ها (mm)، لیست قابل‌ویرایش، ردیف سبز با برچسب «کنترل شد»
- **پلان خیابان‌ها:** نقشه‌ی رنگی همه‌ی خیابان‌ها، لمس برای انتخاب، zoom/pan، تمام‌صفحه
- **پنل خیابان روی پلان:** متراژ، جهت، بالارونده/سرازیر، شیب طولی و عرضی
- پیاده‌سازی، برداشت، مجوز، مصالح و تخلیه
- ورود/خروج CSV، TXT، Excel (.xlsx)، پشتیبان JSON، QR
- کلید امضا، قفل خیابان با هش SHA-256

## اجرا

```text
index.html را در مرورگر باز کنید.
```

برای نصب روی گوشی (PWA)، برنامه را روی `https` منتشر کنید (مثلاً GitHub Pages).

### انتشار روی GitHub Pages

1. مخزن را بسازید و فایل‌ها را روی شاخه‌ی `main` بفرستید.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. بعد از اجرای workflow، آدرس `https://<نام‌کاربری>.github.io/<نام‌مخزن>/` فعال می‌شود.

## داده‌ها و حریم خصوصی

- همه‌ی پروژه‌ها فقط در حافظه‌ی مرورگر (`localStorage`) همان دستگاه ذخیره می‌شوند؛ هیچ داده‌ای به سرور فرستاده نمی‌شود.
- از «پروژه‌ها و پشتیبان» بکاپ JSON بگیرید. فایل‌های پشتیبان را (حاوی اطلاعات کارفرما) در مخزن عمومی نگذارید.

## ساختار

| فایل | شرح |
|---|---|
| `index.html` | کل برنامه |
